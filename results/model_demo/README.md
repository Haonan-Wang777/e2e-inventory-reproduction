# E2E 机制训练演示

此目录由 `scripts/train_demo.py` 生成。它证明公开主干可以实现、训练、保存并重载，**不代表重新训练复现原文 24,333 SKU 的主实验**。

## 数据和人工假设

- 观察数据只使用作者公开的 5 个商品 × 457 天销售序列。
- 公开库存表和交付表的 SKU 与销售表不匹配，因此没有连接这些表。
- 人工设定提前期为 3 天、相邻到货间隔为 14 天，每天构造一个假想下单场景。相邻场景的窗口重叠，统计上并不独立。
- 初始库存为过去 28 天平均销量乘 17 天，再乘 0.3-1.2 间的确定性系数。到货库存为该初始库存减实际到货前需求。此演示使用可为负数的库存/欠货约定。
- 监督标签是给定到货库存和未来 14 天实际需求后，定理 1 所给出的局部区间最优订单；在 250 个随机小例中用所有凸折点独立枚举核验。
- 成本是到货至下次到货前的假想 14 天区间成本，不能与论文原始测试期的成本数值直接对比。

## 训练和评估

时间轴按前 60%、中 20%、后 20% 分为训练、验证、测试。历史输入为 60 天，未来辅助预测为 21 天。任一样本的未来标签都不跨越其分区边界；验证/测试可使用其起点前已发生的真实历史销量。缩放器只在训练期拟合。

网络采用论文公开默认的 MQRNN 隐状态 50、提前期隐藏层 50/20、融合隐藏层 100/100、dropout 0.2、batch 64、学习率 0.001、momentum 0.85、Gaussian(0,0.01) 初始化。SGD、context/bridge 维度 8、三个分位点 0.1/0.5/0.9、辅助权重及 MSE 主损失是本次演示选择，见 `config.json`。

`best_validation.pt` 根据验证总损失选择。测试集只用于最后报告，不参与选模型。无论是否优于简单历史均值策略，都保留实际输出。

## 输出

| 文件 | 内容 |
|---|---|
| `config.json` | 全部配置、数据来源、假设、缩放参数、分区边界和样本数 |
| `metrics.json` | 初始/训练后损失、验证最优轮数、测试误差、假想场景成本和一致性检查 |
| `training_history.csv` | 每轮训练/验证损失 |
| `test_predictions.csv` | 每个测试场景按公开销量计算的标签、模型与均值策略订单、各项成本 |
| `gradient_check.json` | 首批次梯度存在性/有限性和参数更新幅度 |
| `best_validation.pt` | 本次创建的最优验证 checkpoint，包含配置及优化器状态 |
| `learning_curve.png` | 训练曲线和场景成本图 |

在项目根目录重跑：

```powershell
& .venv/Scripts/python.exe scripts/train_demo.py --epochs 100 --seed 4564
```

未来若拿到完整真实订单、提前期和库存数据，应更换场景构造器并重新验证数据切分；当前演示结果不能用于实际补货决策或评价作者在真实业务中的效果。
